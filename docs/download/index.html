Academy Manager

Local-first desktop app for academy management and private bookkeeping — payment records and receipts for your own files, not legal invoicing.

Features

  • Students, courses, class groups, and enrollments
  • Batch and manual internal payment records with PDF export
  • Reports, global search, and payment history with PDF preview
  • One-click backup and restore (.academy-manager-backup.zip)
  • Spanish default UI with English in Settings

Download

Installers are published on tagged releases. Pick the build for your operating system (Linux .deb or AppImage, Windows .msi).

View releases

New to the app? After install, the onboarding wizard walks you through academy name, locale, and optional auto-backup.

Getting started

  1. Download and install the bundle for your OS from Releases.
  2. Complete the first-run wizard (name, language, backup folder optional).
  3. Add students manually or import CSV/Excel from the Students screen.
  4. Use Billing to generate monthly payment records and export PDFs.
